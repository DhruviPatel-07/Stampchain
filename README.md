# StampChain 🚚

### Logistics Tracking Prototype

StampChain is a project we tried to build as a team during our college hackathon, Mecia. The idea was to make shipment tracking easier to understand by bringing shipment details, delivery progress, and checkpoint updates together in one place.

This project is our attempt at turning that idea into a working frontend prototype. It gives a basic idea of how the actual platform could look and how its different features might work.

## Features

- **Dashboard:** View shipment details, delivery status, and recent activity.
- **Shipment Tracking:** Explore shipment information and delivery progress.
- **Interactive Map:** View trucks, warehouses, checkpoints, and routes through a pixel-art map.
- **Checkpoint Monitoring:** Check checkpoint details and shipment updates.
- **Alerts:** View alerts related to shipment activities.
- **Different User Views:** Explore the dashboard as an Admin/Dispatcher, Driver, Warehouse Staff, or Receiver.
- **Analytics:** View sample shipment statistics and activity records.

## About This Project

This is only a frontend prototype that we tried to develop during the hackathon. It is not the actual or complete StampChain platform.

The actual platform would require further development, including a backend, database, real-time GPS tracking, proper user authentication, and other features needed to make the system work in real-world logistics.

For now, this prototype uses sample shipment data and simulated tracking updates to demonstrate our idea and its possible interface.

## Run Locally

2. Open the project folder.
3. Open `index.html` in your browser.
